# usamaarshad.me

Personal portfolio of **Usama Arshad** — Offensive Security Lead (Red Team · Fintech & Cloud), Riyadh.

Live at [www.usamaarshad.me](https://www.usamaarshad.me), served by GitHub Pages.

## Stack

Deliberately boring: one hand-written `index.html` with inline CSS and vanilla JS. No framework, no build step, no trackers, no cookies. Fonts from Google Fonts (Fraunces, Inter, JetBrains Mono); everything else is self-contained.

## Structure

```
index.html    — the whole site
404.html      — not-found page
avatar.jpg    — profile image (also the OG image)
assets/       — resume PDF, favicon, touch icon
CNAME         — custom domain
.nojekyll     — disables Jekyll processing on Pages
```

## Local preview

```sh
python3 -m http.server 8000
# open http://localhost:8000
```
