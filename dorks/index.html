Reconnaissance Attack surface discovery 118 queries

Recon Tool · Dork Library

Finding what should not be public.

A working set of search-engine queries for mapping attack surface. Drop in a target domain and every query scopes to it; pick a search engine and the run links retarget. It opens with combined sweeps that OR many patterns into one query, then the WordPress REST and AJAX patterns behind 59 assigned CVE IDs.

01

Before you run anything

Scope and intent.

These queries only read a search engine's index. They touch no target system, which is exactly why they are the first thing to run and the last thing to be noticed. Everything here is public information that someone intended to keep private.

Run them against assets you own or are authorised to test. A result that discloses third-party data is a finding to report through the appropriate channel, not something to collect. My own WordPress research follows that rule: reproduce in a local lab, report through WPScan, and publish nothing until the vendor ships a fix.

Narrow every query with site: before you run it. A dork without a scope operator is a survey of the internet; a dork with one is reconnaissance.
