WordPressREST entry points, the rest_route alias and AJAX actions. Open ↗

Enumerates WordPress users through the core REST route. The starting point for most plugin-side authorization work.

Run ↗

Surfaces the plugin REST namespaces registered on a host. Each namespace is a permission_callback waiting to be checked.

Run ↗

Exposed AJAX actions. Unprotected wp_ajax_nopriv_ handlers are where unauthenticated writes tend to live.

Run ↗

Directory listing over the plugins folder: exact plugin inventory and versions without touching an endpoint.

inurl:wp-content/debug.log

Run ↗

WP_DEBUG_LOG left enabled. Leaks paths, SQL, nonces and occasionally tokens.

inurl:wp-content/uploads ext:sql | ext:zip | ext:tar.gz

Run ↗

Database dumps and archives dropped into the uploads directory, which is world readable by design.

Run ↗

Plugin readme files give the exact stable version, which is how you map a host to a known advisory.

intext:"wp-config.php" ext:bak | ext:old | ext:save | ext:txt

Run ↗

Backed-up wp-config files containing DB credentials and auth salts.
