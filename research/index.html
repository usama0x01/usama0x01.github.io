Fifty-one are catalogued above with their advisory links. The rest are assigned and go live as each vendor finishes its fix cycle.

Nothing unpatched is described here. No plugin name, version, endpoint, parameter, or proof of concept is published while a finding is still live, because that would hand attackers a working map.

Vulnerability-class mix across the corpus

  • Sensitive Data Disclosure
  • Broken Access Control / Missing Authorization
  • IDOR
  • CSRF
  • SQL Injection
  • Cross-Site Scripting
  • Authentication Bypass
  • RCE (1×)

Access levels: predominantly unauthenticated, plus a minority requiring only low-privilege access (Subscriber or Contributor).

03

Policy

Responsible disclosure.

Every vulnerability here was reported privately first. Nothing is published while a finding is still unpatched: not the plugin name, version, endpoint, parameter, or proof of concept. Publishing early would hand attackers a working map. Details go public only after the vendor ships a fix and, where applicable, a CVE is assigned.
